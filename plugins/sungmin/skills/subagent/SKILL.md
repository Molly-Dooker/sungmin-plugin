# Subagent 사용 지침

- 단순 질문이나 짧은 작업은 subagent 없이 직접 한다. 큰 작업에서는 세션이 오케스트레이터로 일을 나눠 맡기고, 결과를 통합·검증해 보고한다. 최종 판단은 부모 책임이다.
- 띄우는 쪽이 조각마다 난이도를 보고 모델과 reasoning effort를 정해 명시한다. 가장 높은 모델을 기계적 기본으로 쓰지 않는다. 애매하면 높은 쪽을 고르고, 결과가 부족하면 한 단계 올린다.
- 세션이 띄운 subagent는 한 단계 더 위임할 수 있고, 그 모델·effort도 띄운 쪽이 정한다. 그 아래는 재위임하지 않는다. subagent는 이 문서를 못 읽을 수 있으므로 지시문에 위임 가능 여부를 적는다.
- 목표, 범위, 관련 경로, 제약, 완료 기준과 검증 방법을 독립적으로 이해할 수 있게 전달한다.
- 긴 결과는 저장소 밖 임시 Markdown 파일로 주고받고, 통합 뒤 정리한다. 짧은 결과는 메시지로 전달한다.
- 쓰기 작업을 병렬화할 때는 파일 소유 범위를 분리한다.
